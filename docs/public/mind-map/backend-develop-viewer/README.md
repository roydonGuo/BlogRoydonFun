# 框架思维导图 Demo

这是从 `框架.xmind` 解析并生成的纯前端 Demo，包含完整的 834 个主题和 97 张配图。

## 运行

直接双击 `index.html` 即可使用，无需安装依赖、无需联网。

## 交互

- 点击节点：展开或收起子主题，并查看完整内容
- 节点配图：XMind 中的图片直接显示在对应节点内，并保持原始比例
- 节点调宽：将鼠标移到节点外侧边缘，左右拖拽即可单独调整该节点宽度
- 拖拽空白画布：平移导图
- 鼠标滚轮：以指针位置为中心缩放
- 搜索框：搜索全部主题并定位（快捷键 `Ctrl + K`）
- “适应画布”：自动缩放到当前可见内容
- “收起”：一键收起所有一级分支

## 文件说明

- `index.html`：页面结构
- `styles.css`：视觉样式与响应式布局
- `app.js`：导图布局、交互、搜索和缩放逻辑
- `data.js`：由 XMind 内容转换出的完整树形数据
- `assets/`：XMind 内嵌配图
